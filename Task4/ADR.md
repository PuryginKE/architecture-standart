### <a name="_bjrr7veeh80c"></a>**Альтернативы**

- Использование API — невозможно для партнёрского колл-центра
- Использование SFTP — не поддерживается внешней системой
- Использование защищённой почты или выгрузки вручную — допустимый и реализуемый вариант

**Недостатки, ограничения, риски**

**Недостаток**

1. Дублирование каналов доставки данных — API для внутреннего колл-центра и файл для партнёрского увеличивают сложность поддержки и тестирования.
2. Ограниченность обновлений в партнёрском канале — ставки передаются один раз в день, без возможности онлайн-обновления.
3. Ограниченная прозрачность партнёрской системы — нет контроля над тем, как именно они отображают ставки или обновляют данные.
4. Отсутствие единого интерфейса управления ставками — изменение ставок потребует ручных действий или администрирования в нескольких местах.
5. Отсутствие двусторонней связи — партнёрский колл-центр не может подтвердить факт получения или корректности файла, если это не настроено отдельно

**Ограничение**

1. Невозможность интеграции через API с партнёром — из-за ограничений внешней системы мы вынуждены использовать устаревший способ через файлы.
2. Формат обмена должен быть максимально простым (CSV/XLSX) — ограничивает расширение метаданных или вложенной структуры ставок.
3. Отсутствие полной автоматизации — актуализация ставок в MVP ещё не интегрирована с CRM, личным кабинетом, мобильным банком.
4. Отсутствие механизма обратной связи — банк не узнает, насколько актуальны ставки, используемые партнёрами, если они не уведомят вручную.
5. Нет резервного канала передачи ставок — при сбое выгрузки или проблеме с почтой/доступом партнёр остаётся без данных.

**Риски**

1. Сбой генерации файла со ставками — партнёр не получит актуальные данные.
2. Файл не доставлен партнёру — сбой в канале доставки (например, email).
3. Устаревшие ставки в API — оператор видит неактуальную информацию.
4. Ошибки отображения ставок — сбой в формате или интерфейсе.
5. Перегрузка колл-центра — много звонков после запуска маркетинга.
6. Пожилые клиенты не понимают процесс — идут звонить вместо онлайн-заявки.
7. Несогласованность ставок — на сайте одни, по телефону другие.
8. Ручное изменение файла — приводит к ошибочным ставкам.
9. Нет подтверждения получения файла партнёром — неизвестно, использует ли он актуальные данные.
10. Риски безопасности — файл могут перехватить или подменить.
