| | | 3. Клиент выбирает депозит и нажимает на кнопку "Подать заявку".
| | | 4. Клиент вводит свои Ф.И.О. и номер телефона.
| | | 5. Клиент отправляет заявку.

| **3** | Клиент, Интернет-банк | Подача заявки на депозит через интернет-банк | 1. Клиент авторизуется в интернет-банке.
| | | 2. Клиент переходит на страницу депозитов.
| | | 3. Клиент видит список доступных депозитов с персонализированными ставками.
| | | 4. Клиент выбирает депозит и нажимает на кнопку "Подать заявку".
| | | 5. Клиент указывает счёт и сумму депозита.
| | | 6. Клиент отправляет заявку и получает СМС-код для подтверждения.
| | | 7. Клиент вводит СМС-код для подтверждения операции.
| | | 8. Заявка отправляется в бэк-офис для обработки.

### <a name="_u8xz25hbrgql"></a>**Нефункциональные требования**

| **№** | **Требование** |
| **1** | Высокая доступность системы (99,9%) - системы должны быть доступны 24/7. |
| **2** | Защита чувствительной информации с помощью шифрования трафика - соблюдение требований безопасности. |
| **3** | Использование резервного ЦОД в случае сбоев - переключение на резервный ЦОД в случае сбоев. |
| **4** | Высокая производительность (операции должны выполняться в течение миллисекунд). |
| **5** | Операции не должны замедлять работу системы - база данных АБС не должна перегружаться. |
| **6** | Разработка документации для дальнейшего расширения системы - важно для оптимизации дальнейшего развития. |
| **7** | Использование технологий, с которыми банк уже знаком (MS SQL и Oracle) - минимизация затрат на внедрение. |
| **8** | Внедрение новых технологий с учетом совместимости - поддержка Kafka, но с учетом ограничений. |
| **9** | Соблюдение брендинга и системы дизайна компании - повышение узнаваемости и удобства использования. |
| **10** | Масштабируемость системы - равномерное горизонтальное масштабирование и распределение запросов между серверами, приложениями и ЦОД. |
| **11** | Использование микросервисной архитектуры для интернет-банка - улучшение гибкости и отказоустойчивости. |
| **12** | Использование очередей сообщений (Kafka) - современные решения для обработки данных. |
| **13** | Ограничения в масштабировании АБС (только вертикальное) - АБС может масштабироваться только вертикально. |
